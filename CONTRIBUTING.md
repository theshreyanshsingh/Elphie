# Contributing to Elphie AI

Welcome to Elphie AI! Thank you for your interest in contributing.

Elphie AI is a comprehensive voice agent platform that helps developers build, test, and deploy conversational AI systems with minimal setup. This guide will help you understand the project structure, set up your development environment, and start contributing effectively.

👉 Join our community → [Elphie Community Slack](https://join.slack.com/t/elphie-community/shared_invite/zt-3zjb5vwvl-j7hRz3_F1SOn5cH~jm5f5g)

## Project Overview

### What is Elphie AI?

Elphie AI is a full-stack platform for building voice agents with a drag-and-drop workflow builder. It combines multiple technologies to provide a seamless experience from development to production deployment.

## How You Can Contribute

- Report bugs and suggest features via [Elphie Community Slack](https://join.slack.com/t/elphie-community/shared_invite/zt-3zjb5vwvl-j7hRz3_F1SOn5cH~jm5f5g)
- Submit pull requests
- Improve documentation — the documentation is hosted via Mintlify and the code is in the `docs/` folder
- Join the Slack community

## Development Setup

Please refer to our [Development Setup documentation](https://elphie.willowave.in/contribution/setup).

### Getting Help

**Before You Start**

- Join our [Slack community](https://join.slack.com/t/elphie-community/shared_invite/zt-3zjb5vwvl-j7hRz3_F1SOn5cH~jm5f5g) to discuss your plans

**During Development**

- Ask questions in our Slack community
