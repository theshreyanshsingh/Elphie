# Security Policy

At Elphie we look forward to working with security researchers across the world to keep Elphie and our users safe. If you have found an issue in any of our services, please reach out to us.

## Supported Versions
We always recommend using the latest versions of services to ensure you get all security updates

## Reporting a Vulnerability

If you believe you have found a security vulnerability within Elphie, please let us know right away. We'll try and fix the problem as soon as possible.

**Do not report vulnerabilities in public channels.** Instead, report the issue via [Elphie Community Slack](https://join.slack.com/t/elphie-community/shared_invite/zt-3zjb5vwvl-j7hRz3_F1SOn5cH~jm5f5g) (DM the maintainers) or email the team through your account contact.

Once we've received your report we'll keep you updated as we fix the vulnerability.

## Thanks

Thank you for keeping Elphie and our users safe.
